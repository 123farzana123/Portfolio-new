# Farzana Yaqubi — Portfolio

Personal portfolio site built to showcase web development projects, technical skills,
and experience.

**Live site:** https://123farzana123.github.io/Portfolio-new/

## Built with

- HTML5, CSS3 (custom design system, no framework)
- Vanilla JavaScript
- Formspree for the contact form

## Structure

```
index.html      main page (single-page site)
style.css       styles / design tokens
script.js       nav toggle + contact form handling
favicon.svg     site icon
```

## Deployment

Hosted live on GitHub Pages, served directly from this repo's `main` branch.
